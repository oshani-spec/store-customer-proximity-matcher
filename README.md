# store-customer-proximity-matcher
Python project for nearest store to customers using geospatial analysis. 

## Overview
This project identifies the nearest store for each customer using geospatial analysis.

## Features
- Address geocoding using OpenStreetMap
- Distance calculation using geodesic method
- Automatic nearest store assignment
- CSV output generation
- Interactive map visualization

## Tech Stack
- Python
- Pandas
- Geopy
- Folium

## Files
- customers.csv
- stores.csv
- output.csv
- map.html
- notebook.ipynb

## How to Run
1. Open Google Colab
2. Upload CSV files
3. Run the notebook
4. Download results

## Sample Output
Customer → Nearest Store → Distance

- Logistics optimization
- Delivery systems
- Ride-sharing algorithms
